# 午间岛 部署指南

## 1. 后端

### 开发环境

```bash
cd backend
npm install
npm start              # http://localhost:3000（实时通道 ws://localhost:3000/ws）
npm test               # 冒烟测试 + 邮件未配置生产失败用例（自动用临时数据目录 + 缩短计时启动服务，跑完即关）
node smoke-test.js     # 对已运行的服务跑同一套测试（需先 rm -rf data；计时类用例会按真实时长跳过或等待）
```

### 生产环境

1. **持久化**：V1 使用 JSON 文件（`backend/data/db.json`）。生产请替换为 PostgreSQL——`src/db.js` 的 `load/save` 与各路由的 `load()` 查询是仅有的数据访问点，可平移为 ORM 查询。
2. **进程管理**：`pm2 start src/index.js --name wujian-dao`；反向代理建议 Nginx + HTTPS。
3. **环境变量**：
   - `PORT`（默认 3000）
   - `NODE_ENV=production`（关闭验证码 devCode 回传）
   - `DATA_DIR`（数据目录）
   - `CORS_ORIGINS`：H5 前端域名白名单（逗号分隔；开发模式自动允许 localhost）
   - 地图底图（V1.2：OpenStreetMap 数据，**不需要任何 key**；V1.1 的 `AMAP_JS_KEY` / `AMAP_JS_SECURITY_CODE` / `AMAP_KEY` 已不再使用，可从服务器删除）：
     - 默认：`backend/tiles/*.pmtiles` 存在时由本服务 `/tiles` 提供（HTTP Range）。生成：安装 [go-pmtiles](https://github.com/protomaps/go-pmtiles/releases)，
       运行 `backend/scripts/fetch-tiles.sh [bbox] [maxzoom]`（默认北京中心城区约 11 MB；全国 `73,18,135,54` 约数 GB）
     - `MAP_PMTILES_URL`：PMTiles 放到国内对象存储 / CDN 时的地址（需开启 Range 与 CORS：`Access-Control-Allow-Headers: Range`）
     - `MAP_STYLE_URL`：改用任意 MapLibre 样式（例如 `https://tiles.openfreemap.org/styles/positron`，境外服务器，国内可能较慢）；`MAP_ATTRIBUTION` 可覆盖署名
     - `MAP_GLYPHS_URL`：字形地址（默认 `/tiles/fonts/{fontstack}/{range}.pbf`，仓库已带 Noto Sans 三段，OFL 许可）
     - `TILES_DIR`：PMTiles 与字形所在目录（默认 `backend/tiles`）
     - 都没有时自动用 OpenFreeMap；底图加载失败时地图页显示“相对位置视图”，位置共享与对讲照常可用
   - 测试专用（**生产不要设置**）：`RT_LOC_TIME_SCALE`、`RT_PTT_MAX_MS`、`RT_PTT_IDLE_MS`
   - **阿里云邮件推送（DirectMail，邮箱验证码）**：请运营方自行在阿里云开通「邮件推送」、验证发信域名/地址，再把凭证放进环境变量，**不要写进代码或仓库**。官方文档：https://help.aliyun.com/zh/direct-mail/sdk-manual ；API `SingleSendMail`（2015-11-23）。本仓库使用官方 SDK `@alicloud/dm20151123`。
     - `ALIBABA_CLOUD_ACCESS_KEY_ID` / `ALIBABA_CLOUD_ACCESS_KEY_SECRET`（阿里云官方约定的访问密钥环境变量名）
     - `ALIDM_ACCOUNT_NAME`：已验证的发信地址
     - `ALIDM_FROM_ALIAS`：可选，发信人显示名，默认「午间岛」
     - `ALIDM_ENDPOINT`：可选，默认 `dm.aliyuncs.com`（其他地域见控制台）
     - `NODE_ENV=production` 且上述三项不完整时，`POST /api/auth/email-code` 必须返回失败（503），**不得假装已发送**，也不得回传 `devCode`
     - 非生产且未配置时，行为与短信 `devCode` 相同，便于本地和 e2e；一旦配置了完整凭证，即使非生产也会真实发信
   - **第三方登录（预留，默认未开通）**：未配齐时点击登录按钮只提示「尚未开通」，接口返回 503，**不会签发登录态**。配齐后仍须完成身份令牌核验才能上线；当前实现在已配置时返回 501，避免半成品误登录。
     - 微信：`WECHAT_APP_ID`、`WECHAT_APP_SECRET`
     - Sign in with Apple：`APPLE_CLIENT_ID`、`APPLE_TEAM_ID`、`APPLE_KEY_ID`、`APPLE_PRIVATE_KEY`
     - 支付宝：`ALIPAY_APP_ID`、`ALIPAY_PRIVATE_KEY`
4. **实时通道（WebSocket `/ws`）**：反向代理必须放行 Upgrade，并把超时调长（心跳 25 秒）：

   ```nginx
   location /ws {
     proxy_pass http://127.0.0.1:3000;
     proxy_http_version 1.1;
     proxy_set_header Upgrade $http_upgrade;
     proxy_set_header Connection "upgrade";
     proxy_read_timeout 120s;
   }
   # V1.2 地图底图（PMTiles 用 HTTP Range 读取；若交给 nginx 直接托管，需保留 Range 与 CORS）
   location /tiles/ {
     proxy_pass http://127.0.0.1:3000;
     proxy_set_header Range $http_range;
     proxy_force_ranges on;
   }
   ```

   - 上线必须 **HTTPS / WSS**：浏览器只允许 HTTPS 页面使用麦克风；微信小程序要求 `wss://` 且域名加入“socket 合法域名”
   - V1 状态在单进程内存中（话权、共享中的最后位置），**只能单实例运行**；多实例需先迁到 Redis（见 docs/对讲与位置共享设计.md §6）
   - 带宽：每路对讲约 64 kbps 上行 + 64 kbps 下行（服务器进出各一份）
5. **H5 同源托管（可选）**：`cd frontend && VITE_API_BASE= npm run build:h5` 后，后端会自动托管 `frontend/dist/build/h5`（或用 `H5_DIR` 指定），手机浏览器直接打开后端域名即可

### 三方服务替换点（Mock → 持牌服务商）

| Mock 位置 | 替换为 |
| --- | --- |
| `routes/auth.js` 短信验证码 | 持牌短信服务商（阿里云/腾讯云 SMS） |
| `services/mail.js` 邮箱验证码 | 已接阿里云邮件推送官方 SDK；需自行开通并配置上方环境变量 |
| `routes/cert.js` orderPay（直接成功） | 微信支付/支付宝**普通商户收款**（平台为收款商户；iOS 端如开放付费解锁走 Apple IAP） |
| `routes/cert.js` provider-callback | 实名认证服务商回调（回调签名校验） |
| `routes/nameview.js` mock 支付 | 同 orderPay |
| 消息轮询（前端 5s setInterval） | 可复用 V1.1 的 `/ws` 实时通道推送新消息 |
| App 端对讲采集 / 播放（未内置） | 原生实时录音插件，经 `frontend/src/realtime/audio.js` 的 `registerAudioProvider()` 注入 |

## 2. 前端（四端构建）

### 前置

```bash
cd frontend
npm install   # 构建脚本会先运行 scripts/vendor-map.mjs，把 MapLibre / pmtiles 拷进 static/{h5,app}/map
# 填写 src/manifest.json：
#   mp-weixin.appid = 你的小程序 AppID
# 后端地址：构建时用环境变量 VITE_API_BASE 指定，例如
#   VITE_API_BASE=https://api.example.cn npm run build:mp-weixin
# 实时通道地址自动由它推导（https → wss + /ws）
```

### 微信小程序

```bash
npm run dev:mp-weixin     # 产物 dist/dev/mp-weixin，用微信开发者工具导入
npm run build:mp-weixin   # dist/build/mp-weixin，上传提审
```

提审前在微信公众平台：申请 `getLocation`、`startLocationUpdate`、`onLocationChange` 隐私接口（`applyPrivacyInterface`）、完善《用户隐私保护指引》（位置信息 + 麦克风）、类目选**社交-即时通信**、上传 B25 许可证；“开发管理 → 服务器域名”加入 `request` 合法域名与 `socket` 合法域名（wss）。
小程序地图用原生 `<map>`（腾讯地图），不能加载 OSM 瓦片（见 docs/V1.2-界面与地图改版.md §2.3）。

### Android App

```bash
npm run build:app        # HBuilderX 云打包（或本地 gradle）
```

安卓权限已按最小化配置（定位 + 网络 + 麦克风）。**App 端实时对讲需要先接入原生实时录音插件**（uni-app 的 `getRecorderManager` 在 App 不支持分片回调），未接入时对讲按钮显示“不可用”，位置共享不受影响。上架前完成《安全评估报告》与 ICP 截图材料。

### iOS App

```bash
npm run build:app        # HBuilderX 云打包 iOS 证书签名
```

**上架红线自查**：
- 仅 `NSLocationWhenInUseUsageDescription`（已配置，无 Always）✅
- `NSMicrophoneUsageDescription`（V1.1 对讲）✅
- App 内账号删除入口 ✅
- 付费查看姓名入口已隐藏（服务端 + 客户端双层）✅
- 隐私政策公网 URL ☐ 待部署 docs/隐私权政策.md

### HarmonyOS

```bash
npm run build:app-harmony   # 需 HBuilderX 4.x+，选择 HarmonyOS 发行目标
```

产物导入 DevEco Studio 签名上架华为 AppGallery。V1.1 需在 harmony-configs 的 `module.json5` 声明 `ohos.permission.MICROPHONE`、`ohos.permission.APPROXIMATELY_LOCATION`、`ohos.permission.LOCATION`（本仓库未生成该文件）。

```
┌─────────────┬─────────────┬─────────────┬─────────────┐
│  微信小程序  │ Android App │   iOS App   │ HarmonyOS   │

                            │  uni-app（一套 Vue3 代码）

      REST /api/*（x-platform 功能开关） + WebSocket /ws（对讲 / 位置共享）

                    午间岛后端（Express）
       ┌──────────────┬─────┴──────────┬──────────────┐
       │ 权限矩阵服务  │ 认证状态机     │ 功能开关      │

       └───────────────────────────────────────────────┘
```
