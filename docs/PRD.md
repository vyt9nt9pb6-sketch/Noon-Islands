# 即时通信与实名互认服务 开发需求文档（V1.0）

**产品名**：午间岛
**文档性质**：开发需求 + 合规映射基线
**适用范围**：微信小程序、Android App（国内商店 + Google Play，如有出海计划）、iOS App、HarmonyOS App
**文档目标**：将已确认的产品决策转化为可开发的功能规格，同时将法律与平台合规要求锚定到对应功能点和《服务条款》《隐私权政策》的具体条款编号，供开发、法务、审核三方共用。

> 本文档源自产品定义阶段（DeepSeek 辅助）确认的最终需求，代码实现以本仓库 backend/frontend 为准。

## 1. 产品边界与核心原则

### 1.1 一句话定位

面向组织身份场景的即时通信服务：**同公司直接聊；同集团跨公司需组织认证后方可聊；跨集团可先聊、后增强信任；实名认证是信任增强，不是聊天前置门槛。**

### 1.2 四条不可妥协的原则

| 原则 | 对开发的约束 |
| --- | --- |
| **定位只做一次性距离核验，不存轨迹** | 不保存经纬度，不累积历史位置记录；拒绝定位时仍有替代认证路径 |
| **实名认证逐次授权，同意只对本次请求生效** | 不设置“一次同意、长期有效”的开关；每次查看请求独立弹出、独立拒绝 |
| **代付资金不形成平台资金池** | 付款人直接付给平台，退款原路退回付款人，平台不向被认证人转付任何资金 |
| **认证提交后不可单方撤销** | 支付前必须主动勾选确认；认证提交至服务商后关闭取消/退款入口（失败按规则处理） |

## 2. 组织关系与聊天权限

### 2.1 组织层级

集团 → 公司 → 部门 → 员工（账号）。每个员工账号在同一时间只归属一个公司（离职后组织关系失效，见 2.4）。

### 2.2 聊天权限矩阵

| 关系 | 搜索 | 发起聊天前置条件 | 前置 |
| --- | --- | --- | --- |
| **同公司** | 默认可搜到 | **直接可聊** | 无 |
| **同集团、不同公司** | 默认可搜到 | 需提交申请，对方接受 | **双方均完成组织认证**后，申请才可送达并可被接受 |
| **不同集团** | 默认可搜到 | 需提交申请，对方接受 | 无组织认证前置条件；先聊后认证 |

**关键规则**：同集团跨公司的“组织认证前置”是硬性门槛——任一方未完成或已过期组织认证，申请入口置灰并提示原因。跨集团不设此门槛。

### 2.3 跨集团“先聊后认证”的受限模式

双方均未完成组织认证的跨集团单聊，处于**受限模式**：

| 功能 | 受限模式下是否可用 |
| --- | --- |
| 文字消息 | ✅ 可用 |
| 文件传输 | ❌ 不可用 |
| 语音通话 | ❌ 不可用 |
| 视频通话 | ❌ 不可用 |

会话顶部持续展示提示条：“双方组织身份均未认证，请注意核实对方身份。”任一方完成组织认证后，徽章更新，但**受限模式仅在双方均完成组织认证后才解除**，不因单方认证而自动升级。提供会话内“请求对方完成组织认证”操作按钮。

### 2.4 组织认证

- **有效期**：6 个月。到期前 30 天开始站内提醒续认证。
- **到期后行为**：该用户**新消息发送被阻断**（历史消息保留可读）；对方界面该用户组织徽章变灰“已过期”；续认证成功后恢复收发。
- **离职联动**：企业管理员标记员工离职后，组织认证**立即失效**。

**核验方式（V1 方案A：一次性距离核验）**：

1. 发起组织认证时请求一次定位权限（仅 `While In Use` / 前台定位）；
2. 计算与公司注册地址的距离，仅保存布尔结果与核验时间戳；
3. **不保存经纬度，不写入任何位置历史表**；
4. 拒绝定位授权时提供替代路径：**上传劳动合同、工牌等材料**。该路径只做认证、不做内容核验，也不经企业管理员审核；材料提交后认证立即生效，有效期仍为 6 个月。平台不判断材料真伪。

**频率限制**：同一账号核验失败后，24 小时内最多重新发起 3 次。

## 3. 实名认证

### 3.1 定位与展示

实名认证**不是聊天前置门槛**，仅作信任增强徽章：未实名显示“未实名”文字状态；已实名显示“实名已认证”徽章、**不展示姓名**；付费查看（经单次授权）在本次会话中展示姓名，展示范围不超出该 1v1 会话。组织认证与实名认证**分开显示**。

### 3.2 发起与授权流程（单次、逐次）

```
A 在 1v1 会话中点击“请求查看实名姓名”
        ↓
系统向 B 展示：A 请求查看你的实名姓名，A 已支付费用
        ↓
B 选择：同意本次 / 拒绝本次
        ↓
同意 → 本次会话展示姓名，写入授权日志
拒绝 → 请求关闭，姓名不展示（费用自动原路退回 A）
```

- 同意**只对本次请求生效**；不提供“长期同意/永久关闭”开关；
- 授权日志记录：请求方 ID、被请求方 ID、同意/拒绝、时间、会话 ID。仅用于审计。

### 3.3 法律定性

以付费为条件处理被查看方姓名，属个人信息对价化利用。合法性来自《个人信息保护法》第 13 条第 1 款第 1 项的**单独同意**——每一次请求都是独立、具体的授权。

## 4. 付费、代付与退款

### 4.1 支付路径（按平台分处理）

| 费用类型 | 微信小程序 | iOS App | Android App |
| --- | --- | --- | --- |
| 组织认证核验服务费 | 微信支付普通商户（提审前确认类目） | 如被认定为解锁功能须走 IAP | 微信支付/支付宝普通商户 |
| 实名认证服务费 | 同上 | 同上 | 同上 |
| 付费查看姓名 | V1 不在 iOS 小程序端开放 | **V1 关闭**；后续如开放须走 IAP | 普通商户收款，不得包装为虚拟商品规避类目 |

**V1 硬性约束**：付费查看姓名在 **iOS 端整体关闭**，服务端开关控制，iOS 端不渲染入口。

### 4.2 代付规则

代付人**直接向平台支付**，平台向代付人开具凭证。禁止“代付人→被认证人→平台”结构（资金池风险）。代付前置条件：被认证人已确认接受该笔代付；代付人支付页**主动勾选**（非默认）：“认证提交后不可单方撤销或退款；认证失败按规则处理。”认证提交后取消/退款入口关闭，**无冷静期**。

### 4.3 退款规则

| 失败/取消情形 | 退款对象 | 规则 |
| --- | --- | --- |
| 平台/服务商接口故障 | 代付人（原路） | 全额 |
| 信息不实首次失败 | 代付人（原路） | 可退，支付前协议显著提示 |
| 信息不实后续失败 | — | 不退 |
| 认证成功 | — | 不退 |
| 认证提交前主动取消 | 代付人（原路） | 全额 |

## 5. 认证请求状态机

```
[组织认证]
方式一：发起 → 一次性定位核验 → 通过（6个月有效）/ 不通过（24h 内限 3 次）
方式二：上传劳动合同与工牌（可附其他证明）→ 只认证不核验真伪、无管理员审核 → 立即通过（6个月有效）

[实名认证-付费]
发起方选择付费方（本人/代付）→ 被认证方确认授权+接受代付
→ 代付人支付（主动勾选不可撤销）→【未提交：可取消全额退】
→ 提交服务商（关闭退款入口）→ 成功（不退）/ 失败（区分原因退款）

[付费查看姓名-单次授权]
A 发起查看请求 → B 逐次同意/拒绝 → 同意则本次会话展示（日志留存）
```

## 8. 开发优先级与平台开关

| 优先级 | 功能 | 平台开关 |
| --- | --- | --- |
| P0 | 组织关系与聊天权限 | 全平台 |
| P0 | 组织认证一次性距离核验 + 材料上传替代路径 | 全平台 |

## V1.1 增补：按住说话对讲 + 实时位置共享（仅单聊）

- **对讲**：按住说话、松开结束；同一会话同一时刻只一人讲（话权），对方在讲时显示“对方正在讲话”；对方离线不可讲；单次最长 60 秒。
- **位置共享**：会话内主动开启，需勾选同意（V1.2 起仅首次确认）；**没有时间限制**，一直持续到停止或退出共享页；对方在地图上看到实时移动；共享中持续显示提示并可一键停止；不保存位置历史，退出即删除。
- **同时使用**：位置共享地图页内置“按住说话”按钮。
- **受限模式**（跨集团未双方认证）：两项功能默认不可用，延续“仅文字”规则。
- 详细设计、协议、限制与开源调研：[对讲与位置共享设计.md](对讲与位置共享设计.md)。

## V1.2 增补：早期微信风格 + 模拟对讲机 + 新地图数据 + 首次隐私提示

- **界面**：全部页面改为早期版微信风格（浅灰底、深色标题栏、绿色强调、通栏列表、方形头像、绿/白带尾巴气泡、老式“+”面板、底部 Tab 图标）；素材全部原创，不使用腾讯图片 / 字体。
- **对讲机**：1v1 聊天输入栏左侧的对讲机键打开“模拟对讲机”面板：天线、网罩、LED（发射红 / 接收橙）、PTT 大键（按下动画 + 震动）；不设液晶屏和多余装饰按键；地图页同款横版对讲机。话权、busy、离线规则不变。单次对讲最长 60 秒。
- **地图**：App / H5 底图改为 OpenStreetMap 数据（默认自建 PMTiles，可配置 OpenFreeMap），不再使用高德或 World Map 的数据；小程序仍为微信原生地图。地图常显 OSM 署名。
- **位置共享隐私**：只在第一次使用时弹出隐私提示，“确认并开始共享”即表示同意；同意按账号记录，之后不再询问；“我 → 隐私”可查看与撤回。共享没有时间限制。位置不保存，停止 / 退出共享页 / 断线 / 撤回即删除。地图页“退出”= 停止共享，“收起”= 后台继续共享。

## V1.3 增补：对讲模式与“退出共享”

- **对讲模式**：聊天页打开对讲机后，文字输入栏（输入框、对讲机键、“+”）整行隐藏；对讲面板右上角“退出对讲”回到文字聊天。
- **位置共享页**：原“退出”与底部“停止共享”合并为左上角“退出共享”（= 停止共享 + 删除位置 + 离开）；共享中不再显示底部提示条；尚未共享时底部仍有“共享我的实时位置”入口；右上角“收起”维持（后台继续共享，聊天页顶部横幅可停止）。

## V1.4 增补：邮箱验证码登录、资料页、组织认证材料上传

- **登录 / 注册**：保留手机号短信验证码登录（已有账号，不自动注册）。新增邮箱验证码登录与注册（无密码）。生产环境通过阿里云邮件推送（DirectMail，官方 SDK `@alicloud/dm20151123`）发送验证码；凭证仅来自环境变量，未配置时生产环境必须发送失败，不得假装成功。本地 / 测试未配置时可返回 `devCode`（与短信相同）。新邮箱注册的账号尚未加入组织，不能使用组织认证，需由企业开通组织关系后再认证。
- **第三方登录入口**：登录页提供微信、Apple ID、支付宝入口（早期微信样式）。未配置开放平台凭证时，点击明确提示“尚未开通”，**不会登录**。后端预留 `/api/auth/oauth/:provider` 与环境变量槽位；即使稍后配齐凭证，在核验逻辑完成前仍返回 501，不签发登录态。
- **账号注销入口**：从「我」页「账号与安全」行右侧去掉「注销账号」文字；注销仅保留在「账号与安全」页较下方、较低调处，确认流程不变。
- **组织认证方式二**：原「企业邮箱 + 管理员确认」停用（接口 410）。改为上传劳动合同、工牌等材料；只认证、不做真伪核验、无管理员审核；上传后立即生效 6 个月。方式一定位核验不变。
- **资料页**：通讯录与聊天共用同一资料页（早期微信联系人样式）。从聊天气泡旁的头衔（头像方块，不是显示名）进入：点对方头像看对方资料，点自己头像看自己资料；气泡旁的名字和会话导航标题不可点进资料。自己的资料也可从「我」页头像/姓名/公司行进入。通讯录点整行或头像进入同一页。举报、屏蔽从 1v1 聊天「+」面板移到对方资料页；自己的资料不出现这两项。「+」面板保留查看实名、对讲机、位置共享。
