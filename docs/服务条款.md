# 午间岛《服务条款》（法务撰写基线）

> 本文件为**开发与法务之间的映射基线**，确保每个已确认功能都有条款落点。正式版需法务审定后发布，并部署为可公开访问的 URL（App Store / 微信提审必查）。

**版本**：V1.4 草案 · 生效日期：____

## 1. 服务描述与组织身份（对应 PRD 2.2）

1.1 午间岛提供面向组织身份场景的即时通信服务：同公司用户可直接聊天；同集团不同公司用户需在**双方均完成组织认证**后方可申请并建立会话；跨集团用户可先建立会话（受限模式），后增强信任。

1.2 受限模式下仅支持文字消息；双方均完成组织认证后，文件、语音、视频等功能方可使用。

1.3 用户可通过手机号短信验证码或邮箱验证码登录；邮箱验证码也可用于注册（无密码）。登录页展示的微信、Apple ID、支付宝入口在平台完成开放平台配置并上线前为「尚未开通」，点击不会完成登录。

## 2. 组织认证规则（对应 PRD 2.4）

2.1 组织认证有效期为 **6 个月**，到期前 30 天平台将提醒续认证。

2.2 认证到期后，用户**新消息发送被阻断**，历史消息保留可读；续认证成功后恢复。

2.3 企业标记用户离职后，其组织认证**立即失效**。

2.4 组织认证有两种方式。方式一为**一次性距离核验**：平台仅核验用户当前位置是否在公司注册地址允许半径内，**仅保存“是否在半径内”的布尔结果与核验时间，不保存经纬度、不形成行踪轨迹**。方式二为用户上传劳动合同、工牌等材料：平台只确认已提交规定类型的材料并据此发放认证，**不做内容真伪核验，也不经企业管理员审核**，提交后认证立即生效，有效期仍为 6 个月。用户拒绝定位授权的，可通过方式二完成认证，不因拒绝定位被阻断。尚未加入组织的账号需先由企业开通组织关系后再认证。

2.5 核验失败的，24 小时内最多重新发起 3 次。

## 3. 实名认证服务（对应 PRD 3）

3.1 实名认证为**可选的信任增强服务**，非聊天的前置条件。实名信息由持牌服务商核验，平台不存储证件原图。

3.2 实名认证通过后，会话中仅显示“实名已认证”徽章，**不展示姓名**。

3.3 实名认证服务费按平台规则收取；费用与退款规则见第 5 条。

## 4. 付费查看姓名（对应 PRD 3.2）

4.1 用户 A 向用户 B 发起“查看实名姓名”请求并支付费用后，系统向 B 展示该请求。

4.2 B 的同意**仅对本次请求生效**；A 下一次查看须重新取得 B 的同意。**平台不提供任何“长期同意”或“永久关闭”设置**；每次请求均独立弹出、均可拒绝。

4.3 B 拒绝的，请求关闭，姓名不展示，A 已支付费用**全额原路退回**。

4.4 该功能在 iOS 端暂不开放；开放与否以平台内实际展示为准。

## 5. 费用、代付与退款（对应 PRD 4）

5.1 **代付结构**：代付人**直接向平台支付**，平台作为收款商户向代付人开具凭证。平台不向被认证人转付任何资金，不提供“代付人→被认证人→平台”路径。

5.2 代付前置条件：(a) 被认证人已在平台内确认接受该笔代付；(b) 代付人已在支付页**主动勾选**确认：“认证提交后不可单方撤销或退款；认证失败按规则处理。”该勾选**非默认勾选**。

5.3 **认证提交后不可单方撤销，无冷静期**。仅在“认证未提交”阶段可主动取消并全额退款。

5.4 退款规则：

| 情形 | 退款 |
| --- | --- |
| 平台或服务商接口故障、系统错误 | 全额退回付款人（原路） |
| 用户提交信息不实导致认证失败（同一账号**首次**） | 可退（支付前协议已显著提示） |
| 同一账号**后续**再次因信息不实失败 | 不退 |
| 认证成功 | 不退 |
| 认证提交前付款人主动取消 | 全额退回（原路） |

5.5 iOS 端任何“付费解锁”类功能的开闭遵循第 4.4 条；如后续开放，将按 Apple App Store 要求接入应用内购买（IAP）。

## 6. 用户行为规范

6.1 禁止利用认证功能骚扰他人、伪造组织身份或进行虚假认证；违反者平台可暂停或终止服务。

6.2 会话内提供举报与屏蔽入口；举报由平台核实处理。

## 7. 账号注销（对应 PRD 6.2 / App Store 5.1.1(v)）

7.1 用户可在 **App 内**（我 → 账号与安全页下方 → 注销账号）直接完成账号删除，无需邮件申请。该入口不直接展示在「我」页列表行右侧。

7.2 注销后：账号信息匿名化、组织认证失效、登录态失效、待处理请求关闭；审计必要最小数据按保留期限到期删除。

## 8. 其他

8.1 平台依据《即时通信工具公众信息服务发展管理暂行规定》等法规运营；提审与上架以取得 **B25 类增值电信业务经营许可证**及《安全评估报告》为前置条件。

8.2 本条款未尽事宜见《隐私权政策》。
